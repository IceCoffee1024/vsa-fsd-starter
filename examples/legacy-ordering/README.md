# Legacy Ordering

This example will demonstrate an incremental modernization path for an ordering system using a Vue 3 FSD frontend and a .NET Framework 4.8 Web API 2/OWIN VSA backend.

The example owns full-stack concerns such as API compatibility, authentication boundaries, error handling, composed startup, and end-to-end verification. It may adapt template code, but no template may depend on it.

Status: scaffold only; the backend and frontend applications have not been implemented.
